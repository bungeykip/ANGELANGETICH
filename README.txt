ANGELA NGETICH — JOURNALISM PORTFOLIO
=====================================

FILES
- index.html: portfolio pages and content
- styles.css: responsive styling, green visual theme, animations
- script.js: gallery manager, filters, search, edit/delete, previews and local storage
- assets/: supplied profile photographs

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in a modern browser, or use VS Code with the Live Server extension.
3. No build tools or installation are required.

GALLERY MANAGER
- Use “Add to gallery” to upload an image or video and add its title, category, date and description.
- Use Edit or Delete on each gallery card.
- Click a gallery image/video area to open a larger preview.
- Filter by Photography, Video, Articles or Interviews; search by title, description or category.
- Gallery entries are saved in the browser's localStorage on that device/browser.

IMPORTANT PUBLISHING NOTES
- The current gallery manager stores uploaded media as browser-local data. It is ideal for a local demo or a single-device portfolio.
- For a live website where Angela can upload from different devices and visitors see the same gallery, connect the gallery to a backend such as Supabase or Firebase and add authentication for the portfolio owner.
- Keep the assets folder alongside index.html when uploading the site to hosting.
- Contact links and social profile links are already wired to the details supplied.
